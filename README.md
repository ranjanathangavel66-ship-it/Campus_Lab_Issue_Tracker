Campus Lab Issue Tracker

About

Campus Lab Issue Tracker is a simple web application used to report laboratory equipment problems.

Features

- Report equipment issues
- Enter student and equipment names
- Select issue type
- Save reported issues in the browser
- View issues after refreshing the page

Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

How to Run

1. Download or clone the project.
2. Open "lab.html" in a web browser.
3. Enter the details and click Report Issue.
